# React Core Patterns

Essential React best practices based on official React documentation from [react.dev](https://react.dev).

## Overview

This skill provides fundamental rules that ensure your React code is correct, predictable, and maintainable. These patterns are different from performance optimization—they are about writing React code that works correctly.

## Categories

| Category | Description |
|----------|-------------|
| **Rules of Hooks** | Fundamental rules for using React Hooks correctly |
| **Component Purity** | Ensuring components are pure and idempotent |
| **Effect Best Practices** | When to use (and NOT use) useEffect |
| **State Structure** | How to structure state to avoid bugs |
| **Key Props** | Correct usage of keys in lists |
| **Accessibility** | Basic React accessibility patterns |
